# Веб-интерфейс результатов (Track 2 / Model Z)

Статическая страница на чистом JavaScript: без сборки, без CDN, без внешних
ресурсов. Работает офлайн.

## Как отдаётся

Бэкенд монтирует эту папку по адресу `/app/`. Страница обращается к API того же
источника по относительным путям:

- `GET /v1/results` — список расчётов для селектора в шапке;
- `GET /v1/results/<run_id>` — данные выбранного расчёта.

Открыть: `http://<хост>/app/` (или `/app/index.html`).

## Демо-режим без бэкенда

`index.html?mock=1` загружает `mock/results.json` вместо API — этого достаточно,
чтобы проверить вёрстку и графики. Локально:

```bash
python3 -m http.server 8000 --directory frontend
# затем http://127.0.0.1:8000/index.html?mock=1
```

Скриншот демо-режима: `mock/screenshot.png`.

## Состав

| Файл | Назначение |
| --- | --- |
| `index.html` | каркас экранов: шапка, карточки ЧДД, карта, графики, ограничения, диффы, интерпретация |
| `style.css` | оформление (тёмная шапка, светлый контент, системные шрифты) |
| `app.js` | загрузка данных, SVG-карта, SVG-графики, таблицы |
| `mock/results.json` | фиктивный ответ API, повторяющий контракт |

## Косметические правки

- Цвета, отступы, шрифты — только `style.css`; палитра фона/текста/линий вынесена
  в переменные `:root` (`--bg`, `--panel`, `--ink`, `--muted`, `--line`, `--head`,
  `--accent`).
- Палитра серий и блоков карты — константа `PALETTE` в начале `app.js`.
- Размер маркеров скважин — функция `wellSize`, геометрия карты — `renderMap`
  (`W`, `H`, `pad`).
- Размеры графиков и полей — константы `W, H, L, R, T, B` в функции `chart`.
- Все подписи интерфейса — русские строковые литералы в `index.html` и `app.js`.

Пустые данные (`null`, пустые массивы) страница показывает как прочерки и
сообщения «Нет данных», ошибок при этом не возникает.
