# Conventions and Invariants

- Python: `from __future__ import annotations`, type hints, `X | Y`; зависимости добавлять только через `uv add`.
- Отчёты на русском, без лишнего англоязычного жаргона; формулы в LaTeX; журнал — `docs/roadmap.md` по схеме Plan → Act → Verify → Report.
- Данные: THP в `MODEL_Y` фактически пластовое давление; DobG — жидкость, не газ; 2015-12 мусорный и исключён; нули до старта скважины означают отсутствие скважины (`WEFF=0`), не нулевой дебит.
- Метрика по умолчанию WAPE: MAPE не использовать как основную из-за полностью обводнённой скважины 1 и близких к нулю рядов.
- Единицы: закачка м³, добыча т; преобразования единиц должны быть явными.
- Бэктест не должен видеть будущие факты. Future-known признаки допустимы только когда это заданный план (например, закачка); стекинг обучать без утечки между срезами.
- Локальные правки → проверка → commit/push → `git pull --ff-only` на a100. Крупные данные, результаты и модели не коммитить.
- Сервер общий: перед GPU-запуском проверять ресурсы; не останавливать и не вытеснять production других проектов.
