# TimesOil Core

- Цель: прогноз нефти и жидкости 33 добывающих скважин на 6 месяцев; 16 нагнетательных, 6 блоков по экранирующим разломам, месячная история 2007-05..2015-11.
- Текущий лучший зафиксированный ансамбль: WAPE 3,74 % нефть / 3,21 % жидкость на трёх канонических срезах. Числа и этапы подтверждать по `docs/roadmap.md`, не по памяти.
- Исходники: `src/timesoil/`; сценарии экспериментов и отчётов: `scripts/`; журнал Plan → Act → Verify → Report: `docs/roadmap.md`.
- Главные модули: `data.py` загрузка/нормализация, `wells.py` фонд и блоки, `backtest.py` срезы/агрегация, `crm*.py` физика связности/давления, `fractional.py` обводнённость, `chronos_runner.py`/`tirex_runner.py` TSFM.
- `raw_data/`, `data/`, `results/`, веса и крупные артефакты вне git; между WSL и a100 передавать `scp -p`.
- Веб-интерфейса нет; проект — Python-библиотека + воспроизводимые CLI-сценарии.
- Для окружений, моделей и версий читать `mem:tech_stack`; для локальных/серверных команд — `mem:suggested_commands`; для проектных инвариантов данных и стиля — `mem:conventions`; для обязательного release gate — `mem:task_completion`.
