Отдельное месячное обучение Y завершено: 115 обучающих окон из пяти физических сценариев, 23 валидационных окна из шестого; три остальных сценария исключены из обучения. Лучший вес выбран на эпохе 28 из 30. По трём ранее исследованным диагностическим сценариям месячный прогноз с фактическим обновлением даёт WAPE нефти 1,68–3,82%, жидкости 1,18–4,51%, RMSE давления 2,28–9,49 бар. Это средние ошибки за 23 месяца, не точность первого месяца нового режима. Новые независимые физические сценарии Y рассчитываются отдельно; вес зафиксирован до их результатов. Отчёт: `timesfm-y-monthly-training.json`.

Новая независимая проверка Z на изменениях BHP также завершена. Расширенное обучение уменьшило ошибку относительно предыдущего эксперимента, однако прямой прогноз 224 месяцев всё ещё даёт на тесте 37,96–47,34% WAPE нефти, 33,51–47,78% жидкости и 72,73–86,15 бар RMSE давления. Предобученный прогноз с ежемесячным фактическим обновлением даёт 1,22–1,89%, 0,59–0,88% и 5,76–6,92 бар соответственно; для давления наивное сохранение предыдущего значения лучше. Широкие интервалы не обеспечивают заявляемой надёжности всей траектории давления. Отчёт: `timesfm-z-independent-bhp.json`. ЧДД обоих треков превышает 15%, но полная цель по точности и надёжности ещё не закрыта.
