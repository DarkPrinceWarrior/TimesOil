# Критерии завершения обоих треков

Цель пользователя: прирост официального ЧДД не менее 15% **отдельно на Model Y и Model Z**, Google TimesFM в прогнозном контуре, агенты Tatneft `qwen3.8-27b`, полное месторождение, доступные управляющие параметры, разломы, ограничения и вся официальная экономика. Это критерии завершения, а не описание уже достигнутого результата.

| Требование | Model Y / трек 1 | Model Z / трек 2 | Доказательство завершения |
|---|---|---|---|
| Прирост ЧДД ≥15% | Не достигнут: подтверждённый цикл 23 месяца даёт 0% | Не достигнут: лучший полный цикл 224 месяца даёт +8,263414% | Сопоставимые полные OPM-прогоны базы и кандидата; неизменные исходные данные, история, период, нормы; проверенные артефакты официального калькулятора |
| Google TimesFM | Прогноз 23 месяцев выполнен; интеграция в выбор месячного управления не завершена | Прогноз 224 месяцев выполнен; точность и UQ/OOD недостаточны | Рабочий прогноз в реальном контуре решения, проверка на независимых режимах управления, интервалы и OOD |
| Минимизация ошибки без утечки | Совместный прогноз лучше двух проверенных раздельных вариантов | Ни один из трёх вариантов группировки не даёт приемлемого полного прогноза | Зафиксированные временные/сценарные разбиения, сравнение с простыми базами, независимые метрики по нефти/жидкости/давлению |
| Tatneft Qwen для всех ролей | Четыре роли и живой API проверены | Четыре роли и живой API проверены | `track1-protocol.json`, `track2-protocol.json`, `tatneft-qwen38-containers.json` |
| Всё месторождение | 49 скважин, полный 23-месячный цикл | 103 скважины, полный 224-месячный цикл | Полная сетка скважина × месяц; исходная геометрия и открытия сохранены |
| Все доступные управляющие параметры | Дебиты, статусы, закачка, пределы BHP, разрешённая конверсия реализованы; новый совместный полный поиск не завершён | Те же параметры; BHP поддержан в данных суррогата, но качество реакции не доказано | C01–C14 в `CONTROL_COST_GAPS_20260909.md`, реальные OPM-проверки каждого применимого действия |
| Разломы | Исходная геология сохранена в OPM; перенос карты блоков старого отчёта требует проверки идентичности | Исходная геология сохранена в OPM; явные признаки связности в прогнозе не завершены | Подтверждённые источником разломы/связность именно соответствующей модели, их использование и проверка в прогнозе |
| Полная экономика | Все 25 фактических норм, 7 методических фиксаций и 12 карточек насосов доступны агенту; официальный помесячный расчёт | Аналогично | Хеши калькулятора/XLSX, одинаковые допущения пары, все строки затрат и событий; неизвестные стоимости не заменяются выдуманными числами |
| Условия организаторов | Не все будущие возмущения предоставлены | Не все будущие возмущения предоставлены | Явные сценарии доступных ограничений; отсутствующие THP/VFP, новые скважины и стоимости перечислены, без заявления о полном покрытии |

## Проверка группировки TimesFM 3

Исходные веса Google, одна точка начала, весь горизонт без будущих наблюдений. Это диагностическая проверка прогноза, не доказательство управляемости или прироста ЧДД. WAPE ниже указан в процентах.

| Модель / входы | Нефть WAPE | Жидкость WAPE | Давление RMSE, бар |
|---|---:|---:|---:|
| Y / все скважины совместно | 10,079 | 3,867 | 21,307 |
| Y / отдельно по скважинам | 12,646 | 5,042 | 23,858 |
| Y / по скважинам + закачка поля | 12,441 | 4,794 | 23,072 |
| Z / все скважины совместно | 95,433 | 43,350 | 71,839 |
| Z / отдельно по скважинам | 94,168 | 51,789 | 79,561 |
| Z / по скважинам + закачка поля | 88,117 | 51,695 | 75,991 |

Доказательства: `deliverables/control_coverage_20260909/timesfm-layout-model-{y,z}.json`; воспроизведение: `scripts/benchmark_timesfm_layouts.py`. Перенос раздельной схемы в рабочий контур по этим результатам не обоснован: Y ухудшается; Z улучшает нефть ценой жидкости и давления.

Исследовательский подбор физических режимов и доработка прогнозного контура идут отдельно. Найденные при подборе режимы не считаются независимой тестовой выборкой. Завершение одной строки не закрывает остальные требования.
