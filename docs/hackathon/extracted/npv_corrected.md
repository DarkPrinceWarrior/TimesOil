Методика расчета чистого дисконтированного дохода (ЧДД) по сценарию управления фондом скважин

1. Назначение и расчетный принцип

Методика предназначена для сопоставления вариантов управления добывающим и нагнетательным фондом по единому экономическому критерию — чистому дисконтированному доходу (ЧДД). Производственные показатели формируются по скважинам на месячном шаге, после чего агрегируются по календарным годам. Экономический расчет выполняется начиная с выбранного пользователем года; этот год принимается первым годом дисконтирования по умолчанию старт расчета. В тестовом сценарии это дата с которой участники управляют фондом 01.01.2014 для трека №1 и 01.01.2007 для трека №2.

В расчете используются месячные объемы добычи нефти, жидкости и закачки, дебит жидкости, приемистость, а также состояние каждой скважины на текущем и предыдущем шагах. Скважина относится к действующему фонду, если на расчетном шаге выполняется хотя бы одно условие: WLPR > 0 или WWIR > 0. Остановленная скважина в действующий фонд не включается.

Событийные затраты определяются автоматически сравнением текущего состояния скважины с предыдущим расчетным шагом. Для смены типоразмера ЭЦН стоимость операции относится в OPEX, а стоимость вновь устанавливаемого насоса — в CAPEX:

Если дебит жидкости остается внутри рабочего интервала установленного ЭЦН, замена не выполняется. При превышении верхней границы выбирается минимальный подходящий больший типоразмер. Переход на меньший типоразмер допускается только при снижении WLPR более чем на 100 м³/сут относительно нижней границы рабочего интервала текущего насоса. При перекрытии диапазонов сохраняется установленный насос, если текущий режим остается допустимым.

Дебит жидкости добывающей скважины свыше 500 м³/сут не допускается.

Остановка и запуск фиксируются как два отдельных платных события по смене состояния работы скважины между соседними шагами. Остановка учитывается при переходе действующей скважины в состояние WLPR = 0 и WWIR = 0, запуск — при обратном переходе в действующий фонд. Стоимость каждого события составляет 1,0 млн руб. На период остановки скважина исключается из действующего фонда, и затраты на содержание фонда по ней не начисляются. Сам по себе запуск не требует установки нового ЭЦН; стоимость нового насоса учитывается только при необходимости смены типоразмера по установленным правилам.

Перевод добывающей скважины под закачку фиксируется (стоимость перевода 5,0 млн руб.), когда на предыдущем шаге скважина работала на добычу, а на текущем добыча прекращена и начинается закачка. Все затраты перевода учитываются в OPEX один раз:

Отдельная стоимость остановки при непосредственном переводе под закачку не начисляется, поскольку скважина остается действующей.

Общий OPEX основной деятельности:

Полный CAPEX включает стоимость новых ЭЦН. На первом расчетном шаге стоимость исходно установленного ЭЦН может учитываться только при включении соответствующей опции расчета; по умолчанию первичное оснащение фонда отдельно не начисляется.

Прибыль до налогообложения рассчитывается после учета OPEX, амортизации, отчислений и прочих доходов/расходов. Амортизация включается в расчетную формулу; при отсутствии заданных значений принимается равной нулю.
