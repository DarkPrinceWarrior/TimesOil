## 6. Копия карточек (verbatim)

Каждая карточка: индекс `01`…`08`, заголовок, ровно 3 буллета, 2–4 чипа. Чип = официальное имя или уже существующая метка текущего SVG. Новых официальных имён не вводить.

### 01 · Приём Model Y

- Официальный архив Model_Y (3).zip. Deck MODEL_Y.DATA, START 01 MAY 2007.
- Сетка 49×47×141. Фонд — 49 скважин. Генератор — tNavigator.
- TimesOil Excel — история для отсева, не deck сдачи.

Чипы: `Model_Y (3).zip` · `MODEL_Y.DATA` · `DemoSpe_002_2_grid.inc` · `DemoSpe_002_2_sch.inc`

### 02 · Кейс и лимиты

- Тестовый кейс — то же поле Model Y. Меняются ограничения и, возможно, история до точки X.
- Текущая выдача — песочница без жёстких лимитов. На тесте ждут лимит воды.
- История до 01.01.2014 — стартовое состояние, не цель оптимизации.

Чипы: `тестовый кейс орг.` · `ТЗ §5.2` · `ТЗ §3.2.3`

### 03 · Состояние фонда

- 33 добывающие + 16 нагнетательных. Блоки A / B / B2 / C / D / E.
- Каноническое состояние: режимы, давления, WEFF, обводнённость.
- THP в выгрузке — пластовое давление. DobG — жидкость. 2015-12 — мусор.

Чипы: `DemoSpe_002_2_sch.inc` · `WELSPECS` · `WCONPROD` · `WCONINJE`

### 04 · Намерения МАС

- Цикл ТЗ: оценка → решение → воздействие → повторная оценка. LLM в ядре обязательна.
- Агенты выбирают действия: стоп, старт, режим, перевод фонда. Не дебиты и не ЧДД.
- TimesOil CRM / CRM2P / CRMP / Джентил — только предварительный отсев.

Чипы: `ControlIntent` · `ConstraintSet` · `decision card`

### 05 · График скважин

- Компилятор пишет include Eclipse / tNavigator. Сдача — wells_schedule.inc, не CSV.
- В цикле — фрагмент месяца; к горизонту — полный файл без ручной правки.
- Parser round-trip обязателен. В файл фиксируется только первый месяц плана.

Чипы: `wells_schedule.inc` · `DATES` · `WCONPROD` · `WCONINJE`

### 06 · Полная ГДМ

- Каждый принятый месяц — полный прогон. ГДМ — физика, не прогнозатор и не деньги.
- Новое состояние берётся из restart, не из CRM и не из LLM.
- TimesOil — отсев кандидатов, не замена этого шага.

Чипы: `MODEL_Y.DATA` · `wells_schedule.inc` · `restart` · `script_1.py`

### 07 · Официальный ЧДД

- Только CHDD_PYTHON, явный --start-year 2014. Других калькуляторов нет.
- 14 полей. Нефть и жидкость — тонны, закачка — м³. Старт учёта 01.01.2014.
- Выход: одно число — заявленный ЧДД, млн руб.

Чипы: `CHDD_PYTHON` · `РАСЧЕТ_ЧДД.py` · `ВХОДНОЙ_ФАЙЛ.txt` · `Нормативы_ЧДД.xlsx`

### 08 · Проверка организаторов

- Этап 1: автовалидация тестового кейса. Рейтинг по заявленному ЧДД.
- Этап 2: один прогон сданного wells_schedule.inc через ГДМ и тот же CHDD_PYTHON.
- Расхождение с заявкой — дисквалификация. Повторных прогонов нет.

Чипы: `wells_schedule.inc` · `заявленный ЧДД` · `CHDD_PYTHON`

## 8. Удалить из текущего SVG

Текущий лист `1600×2200` — высокий столбик. В ландшафте этого нет:

| Удалить | Где сейчас |
|---|---|
| Холст 1600×2200 | `viewBox` / `width` / `height` / колофон |
| Диагональ разлома | `<linearGradient id="fault">` + `<line x1="1288" y1="-40" x2="1088" y2="2240">` — уже за холстом |
| Grain | `<filter id="grain">` + полноформатный `rect` с `filter` |
| 8 стопок по 188 px | `#s01`…`#s08` at y=300,496,692,888,1084,1280,1524,1720; высота 188 |
| Вертикальная золотая ось | линия x=86, y=268…1868 и круги на концах |
| Три колонки строки | «ЭТАП / КОНТУР / ОФИЦИАЛЬНЫЕ ФАЙЛЫ И ПРАВИЛО» |
| Метка «ПЛАСТ 0N» | геология столбика |
| 6–8 строк тела на этап | не влезает в карточку |
| 5–7 чипов + 4 rule-строки | лимит 2–4 чипа, rule уходит в буллет или чип |
| Петля-коробка y=1476 | зажата между 06 и 07 в столбике; заменить рельсом §4 |
| Списки скважин и DATES | номера нагнетательных, блок C, «103 шага DATES» |

| Ростер ролей МАС | координатор+блоки — опция, не требование ТЗ |

Оставить смысл, не декор: официальные имена, три пакета, формула ролей, помесячный возврат 06→03.
