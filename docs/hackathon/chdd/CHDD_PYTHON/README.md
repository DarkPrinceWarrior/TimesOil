# Расчет ЧДД

1. Положите файл исходных данных `.xlsx` или `.csv` в папку `input`.
   Структура столбцов должна соответствовать файлу
   `input/Пример_исходных_данных.xlsx`.
2. Откройте `ВХОДНОЙ_ФАЙЛ.txt` и укажите в единственной строке точное имя
   файла из папки `input`, например `Пример_исходных_данных.xlsx`.
   Путь к файлу указывать не нужно. В папке `input` может находиться несколько
   файлов — для расчета будет взят только указанный в настройке.
3. Проверьте значения в `input/Нормативы_ЧДД.xlsx`.
4. Запустите `РАСЧЕТ_ЧДД.py`.

В Windows можно запустить `ЗАПУСК_WINDOWS.bat`.

Готовый Excel появится в папке `output` с именем
`Расчет_ЧДД_<имя исходного файла>.xlsx`.

## Правило отрицательных строк

Если хотя бы одно из месячных значений `WLPT_Diff`, `WOMT_Diff` или
`WWIT_Diff` отрицательно, строка полностью исключается из экономического
расчета. Она не влияет на добычу, закачку, фонд, события, затраты, FCF и ЧДД.

Полный контрольный CSV в репозиторий не входит. Если файл фактически добавлен
в `input/` и подключено веб-ядро, опциональный parity-тест ожидает исключение
102 строк за `2025-09-01` и исторический ЧДД `4418.1319744583` млн руб.

Поддерживаемый запуск из корня TimesOil использует закреплённую зависимость
`openpyxl>=3.1` из `pyproject.toml` и `uv.lock`:

```bash
uv sync --locked
uv run python docs/hackathon/chdd/CHDD_PYTHON/РАСЧЕТ_ЧДД.py
```

Для технических сценариев выбор из `ВХОДНОЙ_ФАЙЛ.txt` можно разово
переопределить параметром `--input`.
