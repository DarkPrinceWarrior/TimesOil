## Важное ограничение

Строка «Накопленный ЧДД» охватывает все годы, перечисленные в файлах:

- Model Y: 2007–2015;
- Model Z OPM Flow: 1991–2025;
- Model Z tNavigator: 1991 и 1994–2025.

Файлы не содержат помесячный исходник из 14 полей и явно заданную дату начала
расчёта. Поэтому они подтверждают допустимое расхождение симуляторов, но не
заменяют сквозную сверку нашего конвейера с конкурсными датами 01.01.2014 для
Model Y и 01.01.2007 для Model Z. Дату и ожидаемое контрольное значение нужно
письменно подтвердить у трекера.

Собственные результаты калькулятора сохраняются отдельно в
`../CHDD_PYTHON/output/`; эти четыре файла не изменять и не перезаписывать.
