# Трек 1 и трек 2

Оба трека решают одну задачу оптимального управления разработкой: максимизация **чистого дисконтированного дохода** при соблюдении технологических ограничений. Различаются масштаб модели и место полного прогона гидродинамической модели в цикле мультиагентной системы.

| Параметр | Трек 1 · Model Y | Трек 2 · Model Z |
|----------|------------------|------------------|
| **Модель** | Model Y (~49 скважин, 16 нагнетательных, разломы; сетка 49×47×141) | Model Z (~109 скважин; сетка 91×102×59; архив **Model_Z_final_OPM**) |
| **Старт учёта ЧДД** | **01.01.2014** | **01.01.2007** |
| **История модели** | tNavigator, START 01 MAY 2007 | tNavigator 25.1, START 01 JUN 1991 |
| **Гидродинамическая модель в цикле** | **Полный прогон на каждой итерации** МАС | **Суррогат** в переборе; полная ГДМ — **финальная проверка** кандидата |
| **Фокус оценки** | Корректность мультиагентной системы при жёстких ограничениях | Корректность + масштаб поля + скорость и качество суррогата |
| **Сдача сверх общего пакета** | `wells_schedule.inc` + заявленный ЧДД | То же + суррогат и метрики его качества (WAPE и др.) |
| **Веб-интерфейс** | **Обязателен** | **Обязателен** |
| **LLM в ядре МАС** | **Обязателен** | **Обязателен** |
| **Docker, конфиг, инструкция** | Обязательны к валидации | Обязательны к валидации |

## Общий пакет (оба трека)

- исходный код, документация, инструкция запуска;
- конфигурация и Docker;
- **`wells_schedule.inc`** без ручной доработки;
- заявленный ЧДД по методике **`CHDD_PYTHON`**;
- демонстрация на защите **7 + 5** мин.

Подробности проверки и отбора — [submission.md](submission.md). Симуляторы и открытые полигоны — [simulators.md](simulators.md).
