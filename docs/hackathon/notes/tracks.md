# Трек 1 и трек 2

**Одно ТЗ, два трека** — участник выбирает один. Оба решают задачу оптимального управления разработкой: максимизация **NPV (ЧДД)** при соблюдении технологических ограничений. Итог — **`wells_schedule.inc`** и заявленное значение NPV.

Различаются масштаб модели и место полного прогона гидродинамической модели (ГДМ) в цикле мультиагентной системы (МАС).

| Параметр | Трек 1 · Model Y | Трек 2 · Model Z |
|----------|------------------|------------------|
| **Модель** | Model Y (~49 скважин, 16 нагнетательных, разломы; сетка 49×47×141) | Model Z (~109 скважин; сетка 91×102×59; архив **Model_Z_final_OPM**) |
| **Старт учёта ЧДД** | **01.01.2014** | **01.01.2007** |
| **История модели** | tNavigator, START 01 MAY 2007 | tNavigator 25.1, START 01 JUN 1991 |
| **ГДМ в цикле МАС** | **Полный прогон на каждой итерации** | **Суррогат** в переборе; полная ГДМ — **финальная проверка** кандидата |
| **Фокус оценки** | Корректность МАС при жёстких ограничениях | Корректность + масштаб поля + скорость и качество суррогата |
| **Сдача сверх общего пакета** | `wells_schedule.inc` + заявленный ЧДД | То же + суррогат и метрики его качества (WAPE и др.) |

## Общие требования (оба трека)

По [ТЗ](../extracted/tz.md) и [посту канала](../extracted/official_post.md):

- **LLM в ядре агентов** — обязательна (языковая или мультимодальная модель в слое принятия решений).
- **Слой интерпретируемости** — объяснение действий агентов.
- **Простой графический интерфейс** — взаимодействие с МАС и разбор результатов.
- **Управляющие воздействия**: открытие и закрытие скважин; изменение режимов работы; иные допустимые воздействия по постановке задачи.
- **Цикл МАС**: оценка состояния → решение → управляющее воздействие → повторная оценка. Без ручного вмешательства после запуска.
- **Воспроизводимость** на тестовом кейсе организаторов.

## Общий пакет сдачи

- исходный код, документация, инструкция запуска;
- файл конфигурации;
- **Docker-образ или материалы для сборки** — *если используете контейнеризацию* (в онбординге рекомендовали для воспроизводимости; по ТЗ — при контейнеризации);
- **`wells_schedule.inc`** без ручной доработки после генерации;
- заявленный ЧДД по методике **`CHDD_PYTHON`**;
- демонстрация на защите **7 + 5** мин.
