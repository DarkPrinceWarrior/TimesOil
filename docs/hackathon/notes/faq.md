# Частые вопросы

Полная постановка — [ТЗ](../extracted/tz.md). Канал трека 1 — [track1_channel.md](track1_channel.md).

## Обязательна ли LLM в решении?

**Да.** В ядре агентов МАС должна быть языковая (или мультимодальная) модель — [ТЗ §3.1](../extracted/tz.md), [пост канала](../extracted/official_post.md).

## Нужен ли веб-интерфейс?

**Да.** Требуется графический интерфейс, достаточный для работы с МАС и интерпретации результатов — [ТЗ §3.1](../extracted/tz.md). Плюс слой интерпретируемости.

## Можно ли обойтись без Docker?

**Да, если не используете контейнеризацию.** По [ТЗ §3.4](../extracted/tz.md): Docker-образ или материалы для сборки — *при использовании контейнеризации*. В онбординге Docker **рекомендовали** для воспроизводимости, но это не отменяет требования: исходники, документация, инструкция, конфиг, воспроизводимый запуск на тестовом кейсе.

## Можно ли подменить данные организаторов своими?

**Нет**, если регламент не разрешает иное. Решение должно работать на предоставленных материалах — [ТЗ §5.2](../extracted/tz.md).

## Выделят ли вычислительные ресурсы?

**Нет.** Считаете на своих ресурсах (или облачном API для LLM). Решение должно быть проверяемо в среде организаторов — [ТЗ §5.3](../extracted/tz.md), [track1_channel.md](track1_channel.md). Система без отправки данных во внешние облака получит преимущество.

## Будут ли к Model Z приложены дополнительные данные для обучения суррогата или пример JSON системы?

**Нет.** Дополнительных выгрузок прогонов Model Z организаторы не предоставляют. Обучающую гидродинамику для суррогата команда получает **самостоятельным прогоном симулятора** на своих сценариях управления.

Официальный пакет **`CHDD_PYTHON`** показывает формат **Excel/JSON для расчёта ЧДД** (итоговое значение NPV по методике хакатона). Это **не** полный вывод мультиагентной системы и **не** готовый датасет дебитов по скважинам для обучения нейросети.

## Какой архив Model Z использовать?

Модель обновлена до **`Model_Z_final_OPM`**, чтобы уравнять шансы команд на разных симуляторах (в том числе OPM Flow). Используйте **новый zip** из материалов хакатона; устаревший **`Model_Z.zip`** не соответствует финальной постановке.

## Что будет на валидации?

Организаторы один раз прогонят ваш **`wells_schedule.inc`** через гидродинамическую модель и сверят NPV с заявленным. Подробности — [submission.md](submission.md).

## Нужно ли уже сейчас выходить на компенсацию 0,85–1,15 и резать внешнюю воду?

**Нет.** На выданной модели ограничений нет: учить агентов физике и собирать свои прогоны. Коридор компенсации и лимит внешней воды обещаны **в тестовом кейсе**; историю до даты расчёта сменят. Воду, которой не будет, требовать не будут. Сейчас важнее адресная закачка и пластовое давление, а не рекорд ЧДД на свободном режиме.
