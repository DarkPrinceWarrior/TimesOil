# Трек 1 — доказательный комплект КТ2

Это локальный комплект для контрольной точки 2, **не финальная конкурсная заявка** и **не шестимесячная сертификация**.

Проверены две управляющие последовательности на Model Y в OPM Flow 2026.04 за единственный интервал `2014-01-01/2014-02-01`:

- `objective_wells_schedule.inc`: победитель целевой функции, закачка в скважину 2 — 140 м³/сут, ЧДД — 95,469630 млн руб.;
- `wells_schedule.inc`: консервативный вариант без изменения управления, 150 м³/сут, ЧДД — 95,467276 млн руб.

Разница 0,002355 млн руб. доказана только для одного месяца. Улучшение на полном горизонте не доказано, поэтому операторская рекомендация — `wells_schedule.inc` (без изменения). Машиночитаемые значения, SHA-256 и ссылка на A100-квитанцию находятся в `submission.json`.
