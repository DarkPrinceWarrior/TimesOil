# Статус КТ2

Этот файл обновляется только терминальными проверенными результатами.

## Репозиторий и комплект поставки

- исходный код сценарного контура, суррогата, AIOS и расчёта ЧДД;
- Dockerfile, Compose-конфигурация без ключа и инструкция запуска;
- CI: синхронизация lock-файла, компиляция и полный набор тестов.

## Сквозной пайплайн

- управления → OPM Flow → канонический экспорт → ЧДД: реализован;
- базовый сценарий сверяется с опубликованным организаторами диапазоном;
- поиск меняет только управления добывающих скважин и сохраняет покважинную
  закачку базового расписания;
- выбранный суррогатом кандидат проходит отдельный повторный расчёт OPM.

Проверка базового сценария при старте экономики с начала разработки:

- опубликованный диапазон двух симуляторов: **5157,016–5218,945 млн руб.**;
- наш расчёт в совместимом профиле: **5181,184 млн руб.** — внутри диапазона;
- оперативная цель, перебазированная на 2007 год без повторного учёта уже
  установленных насосов: **11918,789 млн руб.**

Разные значения относятся к разным точкам старта экономики и правилам учёта
начальных насосов; смешивать их в одной метрике нельзя.

Терминальный поиск проверил 500 допустимых вариантов. Выбранный по
риск-скорректированному суррогатному критерию кандидат после отдельного прогона
OPM Flow получил **11914,373 млн руб.**, то есть на **4,416 млн руб. ниже**
оперативного базового сценария. Улучшение ЧДД не заявляется: результат
доказывает работоспособность сквозного контура и необходимость опираться на
финальный симулятор, а не на суррогатный критерий. Операционное решение —
сохранить подтверждённую базовую управляющую последовательность; кандидат
№249 остаётся только доказательством проверки через replay.

## Агентный слой

- внешний Qwen `qwen3.6-35b-a3b`, четыре фиксированные роли;
- локальная LLM и автоматический обход численных ворот отсутствуют;
- критик имеет право отклонить неполный или недоказанный план.

Контрольный эксперимент получил **8 из 8** ответов внешней модели, прошёл все
четыре роли и выполнил четыре разрешённых вызова инструментов. Критик отклонил
неполный кандидат — это ожидаемая проверка отказа при недоказанности, а не
ошибка графа.

## Суррогат

- архитектура: физический CRM/material-balance + ансамбль LightGBM по остаткам;
- цель: L1 по нефти, жидкости и давлению с рекурсивным горизонтом 6 месяцев;
- обучение: 8 сценариев, тест: 2 сценария, горизонт 6 месяцев;
- train: WAPE нефти **7,49%**, WAPE жидкости **4,88%**, RMSE давления
  **8,34 бар**;
- test: WAPE нефти **7,71%**, WAPE жидкости **5,11%**, RMSE давления
  **8,45 бар**;
- LOSO: WAPE нефти **7,55%**, WAPE жидкости **4,91%**, RMSE давления
  **8,50 бар**;
- интервалы 90% откалиброваны по десяти сценариям методом LOSO; покрытие на
  калибровочных фолдах не является независимой валидацией;
- артефакт состоит из пяти ансамблевых участников по трём целям, встроен в
  Docker-образ и проверяется по SHA-256 при каждом запросе readiness.
