Полный Model Z: **903 → 213 с (4,23×)**. Подготовленный полный replay
Model Y: **138 → 62 с (2,21×)**. Изменены распределение вычислений и число
параллельных сценариев. Физические параметры, расписание и допуски решателя
в этих сравнениях одинаковые.

## Точность

MPI меняет порядок численных операций и траекторию адаптивных шагов;
побитового совпадения с последовательным расчётом нет.

- Z, 16 MPI: конечная суммарная накопленная нефть отличается на −0,01979%;
  WAPE дебита нефти по скважинам и датам — 0,22091%.
- Z, официальный ЧДД за январь 2007 — август 2025: 11 874,34109 против
  11 873,62064 млн руб., разница **−0,00607%**. Одинаковые 224 месяца,
  нормативы, история насосов и `charge_initial_pump=False`.
- Для отдельных точек Z разница BHP достигает 24,37 бар; 99-й процентиль
  абсолютной разницы — 0,465 бар. Малую среднюю ошибку нельзя считать
  доказательством совпадения каждого ограничения.
- Y, 8 MPI: конечная суммарная накопленная нефть отличается на +0,0000523%;
  WAPE дебита нефти — 0,06995%.

MPI применяется для исследовательских и обучающих прогонов. Финальную
оптимизированную политику необходимо сравнивать с базой в одном режиме и
подтверждать исходным последовательным расчётом. Ранее опубликованные ЧДД
и артефакты этим ускорением не заменены.

## Конфигурация сервера и применение

Два Xeon Platinum 8338C; доступны 64 логических CPU из 128, без CPU-квоты,
около 1 ТиБ RAM. Для двух рабочих процессов выбраны непересекающиеся
наборы физических ядер: `14-29` и `32-47`, по одному NUMA-узлу на сценарий.

Общий `OpmFlowRunner` обоих треков поддерживает:

- `OPM_MPI_PROCESSES`: 1–64, по умолчанию 1.
- `OPM_THREADS_PER_PROCESS`: потоки OpenMP на процесс.
- `OPM_CPU_AFFINITY`: список CPU для `taskset` внутри контейнера.
- `OPM_WORKER_CPU_AFFINITIES`: наборы через `;` для
  `run_track2_scenarios.py`, один набор на каждого `--workers`.

Использованный профиль обучающей серии Z:

```bash
export OPM_MPI_PROCESSES=16 OPM_THREADS_PER_PROCESS=1
export OPM_CPU_AFFINITY=32-47
export OPM_WORKER_CPU_AFFINITIES='14-29;32-47'
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1
python scripts/benchmark_bhp_surrogate.py --source /path/Model_Z_final_OPM.zip \
  --output /path/new-run --workers 2
```

Сначала проверяется identity baseline, затем варианты считаются парами.
Каждая точная команда, образ по digest и контрольные суммы результатов
записываются в manifest. Для новых CPU-наборов нужно проверить фактический
`cpuset.cpus.effective`: эти номера относятся к текущему выделению сервера.

Docker сообщает 2 CPU и отклоняет `--cpuset-cpus`, хотя ядро ОС разрешает
контейнеру 64 CPU. Поэтому используется `taskset` внутри контейнера.
Общий Docker не перезапускался.

## Почему сейчас CPU, хотя сервер имеет шесть A100

OPM поддерживает GPU CPR-AMG и MPI, но используемый закреплённый образ
`openporousmedia/opmreleases:2026.04_amd64` собран без CUDA. Проверены оба пути:
`--linear-solver-accelerator=gpu` возвращает `Unknown backend: gpu`, а
`--accelerator-mode=cusparse` — `CUDA was not found by CMake`.
GPU-сервисы других проектов не изменялись.

Новая GPU-сборка потребует отдельной проверки точности и производительности,
а также обновления контракта закреплённого образа; наличие A100 само по себе
не ускоряет текущий бинарник.
