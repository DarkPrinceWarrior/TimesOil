# Независимая проверка интервалов прогноза Z

Источник `0d9e958`; A100 `/root/projects/TimesOil-audit-fresh-uq-z-20260910`.
Запуск `timesoil-fresh-uq-z-20260910`. [Протокол до расчёта](frozen-protocol.json).
Восемь новых полных физических сценариев на прежнем OPM: 103 скважины,
224 управляемых месяца. Обученные веса, параметры управления, разделение
5 калибровочных / 3 тестовых сценария зафиксированы заранее. Дообучение
или выбор модели по этим сценариям запрещены.

Предыдущие калибровочные сценарии использовались для развития модели,
поэтому их нельзя повторно выдавать за независимую калибровку текущих весов.
Новый запуск проверяет отличие хешей управляющих расписаний от предыдущего
набора. Оценщик также исключает траектории, уже использованные при обучении.

Метод: максимум абсолютной ошибки по целой траектории каждого калибровочного
сценария, отдельно для нефти/жидкости/давления. Проверяются точечное покрытие
и покрытие всех скважин/месяцев тестовой траектории по каждой цели.
Месяцы и скважины не считаются независимыми калибровочными наблюдениями.

[CAFHT, Zhou et al.](https://arxiv.org/html/2402.09623v3) обосновывает разделение
обучения и калибровки и различие точечного/одновременного покрытия. Наша
проверка использует простой фиксированный радиус, не реализует адаптивный
алгоритм CAFHT. Его гарантии требуют обменности траекторий; для восьми
заранее выбранных управлений одного месторождения она не доказана.
Поэтому результат будет эмпирической проверкой, без гарантии переноса на
финальный кейс и без объявления надёжности всех возможных управлений.

Все восемь физических сценариев и оценка завершены: `physics.exit=0`,
`evaluation.exit=0`, итоговый `exit=0`. [Физический манифест](physical-manifest.json),
[протокол](physical-protocol.json), [полный отчёт](evaluation.json).

Интервалы строились по пяти отдельным калибровочным траекториям, до оценки
трёх тестовых. Радиусы для нефти/жидкости/давления: **55,3245 т/сут,
42,2496 т/сут, 186,913 бар**. Полное покрытие тестовой траектории по целям:
**3/3, 2/3, 2/3** при номинальном уровне 80%. Точечное покрытие около 100%
не заменяет покрытия всей траектории. Интервалы широкие; гарантии обменности
и переноса на другие управления/месторождения не заявлены.
`independently_certified_for_surrogate_control=false`.

Это независимое свидетельство оставшейся ошибки, а не допуск автономного
управления. Новые переводы скважин сюда не входят. Режим `naive_observed_update_1`
в отчёте получает новые наблюдения каждый месяц; его меньшая ошибка не является
сопоставимой оценкой прогноза 224 месяцев из одной исходной точки.

[Проверка завершения и хешей](completion-verification.json) подтверждает
восемь траекторий и их экспортные манифесты, неизменные веса/разбиение
и отсутствие будущих наблюдений у фиксированного прогноза.
