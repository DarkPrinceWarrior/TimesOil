Y: 49 скважин × 23 месяца; одновременно изменены дебиты и BHP. Обновление использует только уже наступившие фактические месяцы. Средняя ошибка скрывает переход: в первом месяце обученный прогноз нефти ошибается на **22,48–45,58%**, исходный Google — на 41,74–58,54%. Давление после обучения улучшилось не во всех сценариях. [Полные метрики Y](y-monthly-independent-v2.json).

Z: 103 скважины × 224 месяца. Здесь независимые изменения только BHP в локальной области: дебиты, роли и статусы совпадают с опорным физическим сценарием; для открытых добывающих BHP увеличивается на `15*x` бар, для нагнетательных умножается на `1-0.1*y`; `0≤x≤1`, `0≤y≤1-x/2`. Выход за область отклоняется с требованием полного OPM. Результаты нельзя переносить на изменения дебита, открытие/закрытие или конверсию скважин.

Опорная траектория — ранее рассчитанное физическое будущее другого, заранее известного сценария. Это доступная плановая информация, явно добавленная к прогнозу; будущее проверяемого кандидата не подаётся. Локальная поправка обучена только на пяти старых калибровочных сценариях. Степень выбрана по исключению одного старого сценария; новые тесты не использованы. ## Незавершённое

Дополнительное обучение Y усиливает первый месяц после смены режима и использует только разрешённую старую калибровку; новый физический набор v3 рассчитывается отдельно. Для Z запущено обучение непосредственно разности отклика относительно физического эталона, затем закреплённая оценка. До получения результатов эти модели не заменяют рабочие веса.

Интервалы в JSON — эмпирическая калибровка на пяти сценариях. Это слишком мало для общего обещания надёжности; в абляции Z одновременное покрытие всей траектории давления нарушается на одном из трёх тестов. Автономный суррогат для произвольных режимов не сертифицирован. Каждое принятое управление по-прежнему проверяется полной физикой и официальной экономикой.

[manifest.json](manifest.json) содержит SHA-256 и исходные пути A100; протоколы запуска приложены. Для проверки финансового пакета: `python3 ../verified_20260910/verify.py`.
