# Scorp — Track 2, Model Z

Этот репозиторий содержит **один представляемый график** для второго трека:
`f3-01`, подготовленный к сдаче 11 сентября 2026 года. Команда Scorp прошла
в финал. Общее объявление о 12 финалистах не содержит персональной оценки
ЧДД или протокола проверки каждого ограничения; ниже приведены результаты
сохранённого расчёта команды, а не сертификат организаторов.

Полный контрольный цикл на коде GitLab `final` (`f0ff4bbd`) завершился за
**4 мин 49 с** на A100. Квитанция фиксирует вызов внешней модели
`qwen3.8-27b`, но не сохраняет адрес провайдера. Для повторения используется
только Tatneft LiteLLM.
Квитанция содержит `complete=true`, `critic_approved=true`,
`experimental=true`, `organizer_certified=false`. Это воспроизведение
сохранённого графика, без изменения алгоритма и управляющих воздействий.

## Физические условия и границы доказательства

На отчётных шагах OPM максимум добычи жидкости — 449,7 м³/сут, закачки —
510,0 м³/сут при пределах 600/600. Заданы нижний BHP добывающих 50 атм и
верхний BHP нагнетательных 300 бар; 16 обязательных ремонтных окон включены.
Повторная привязка сырого FPR к времени OPM не выявила значений ниже 108 атм
на отчётных шагах. Проверка не доказывает соблюдение пределов *между*
отчётными шагами.

**Открытый вопрос — VRR.** По трёхмесячной разности накопленных пластовых
объёмов OPM 66 из 224 месяцев попадают в 0,85–1,15; 158 выше 1,15. Кейс
говорит «преимущественно», но не задаёт долю месяцев или обязательную формулу
VRR. При таком прочтении нельзя заявить, что условие соблюдено. В старом
текстовом отчёте фигурировали 130 месяцев превышения: там использованы
поверхностные объёмы и другая привязка окна. Детали — в
[проверках](TRACK2_FINAL_CHECKS.txt). Старое сообщение о шести месяцах с
низким FPR возникло из-за сдвига дат и не подтверждается сырой парой
SMSPEC/TIME.

Исходный запрос `f3-01` не содержит встроенных `operating_constraints`;
квитанция полного цикла сама по себе не доказывает все условия кейса.
Подтверждение прохождения в финал не раскрывает, по какой формуле и с какими
допусками организаторы проверяли VRR. Для точного ответа нужен их персональный
протокол проверки Scorp.

## Повторение сохранённого цикла

Нужен архив Model Z с SHA-256
`e64febb6d843feac06ed70835b09eae05c5cc99f4f5cef9225f1b36b0520653d`
и доступ к Tatneft LiteLLM из сети Татнефти. Архив не хранится в Git; поле
`source` в запросе указывает путь A100. В другой среде меняется только путь к
архиву, если байты архива совпадают. Ключ передаётся через защищённое
окружение.

```bash
export LLM_BASE_URL=https://litellm.tatneft.guru/v1
export LLM_MODEL=qwen3.8-27b
uv run timesoil-aios full-cycle TRACK2_FINAL_REQUEST.json --runs-dir results --run-id final --timeout 7200
```

На GitHub `main` и `track-2-model-z` публикуется этот пакет. GitLab `main` и
`final` сейчас указывают на `f0ff4bbd`: там есть исполняемый код, но нет
сентябрьского графика `f3-01`. Права записи в проект GitLab отсутствуют;
организаторам для сверки нужно передать точный файл и его SHA-256.
