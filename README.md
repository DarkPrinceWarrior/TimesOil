# Scorp — TimesOil, Трек 2

Репозиторий команды **Scorp**: прогноз Google TimesFM 3.0 на полный период
Model Z, поиск управлений по прогнозному ЧДД, фиксация выбора и **одна**
финальная проверка в OPM Flow с официальным ЧДД.

Полный учебный период Model Z — 224 месяца. Точность автономного прогноза
и его неопределённость требуют дальнейшей проверки.

## Финальный пакет Track 2 Model Z

Зафиксирован сценарий `f3-01`: продолжение режима на срезе декабря 2006 года
для 103 скважин на 224 месяца. Он содержит 23 072 помесячных действия.
Прирост к базовому режиму не заявлен. Других выбранных сценариев в итоговом
пакете нет.

| Файл в корне | Что содержит |
| --- | --- |
| `TRACK2_FINAL_REQUEST.json` | Точный запрос с зафиксированными действиями |
| `TRACK2_FINAL_WELLS_SCHEDULE.inc` | Передаваемое организаторам расписание скважин |
| `TRACK2_FINAL_RECEIPT.json` | Квитанция полного контрольного цикла |
| `TRACK2_FINAL_SUMMARY.json` | Период, ЧДД и контрольная сумма расписания |
| `TRACK2_FINAL_CHECKS.txt` | Численные проверки физических ограничений |
| `TRACK2_FINAL_SCHEME.drawio` | Схема данных, расчёта и подтверждений |

27 сентября 2026 года полный контрольный цикл на чистом коде GitLab `final`
(`f0ff4bbd`) занял **4 мин 49 с**. Qwen `qwen3.8-27b` вызывался только через
Tatneft LiteLLM; OPM Flow был запущен на A100. Управления, входное расписание
OPM, SUMMARY и экспортированные физические ряды совпали с сохранённым
сценарием. ЧДД за период управления — **4 287,9469 млн ₽**.

Квитанция подтверждает завершение расчёта и одобрение критика, но помечена
как экспериментальная: сертификации организаторов нет. В запросе не заданы
дополнительные `operating_constraints`. Отдельный `TRACK2_FINAL_CHECKS.txt`
фиксирует 130 месяцев с VRR3 выше 1,15 и 6 месяцев с давлением ниже порога.

Для повторения нужен исходный архив Model Z с SHA-256
`e64febb6d843feac06ed70835b09eae05c5cc99f4f5cef9225f1b36b0520653d`;
он не хранится в Git. Путь `source` в запросе указывает на A100. В другой
среде меняется только этот путь, а помесячные действия остаются прежними.
Установите `LLM_BASE_URL=https://litellm.tatneft.guru/v1`,
`LLM_MODEL=qwen3.8-27b` и ключ в `LLM_API_KEY`, затем запустите:

```bash
timesoil-aios full-cycle TRACK2_FINAL_REQUEST.json --runs-dir results --run-id final --timeout 7200
```

## Рабочая цепочка Трека 2

Ниже описан этап разработки. Для проверки зафиксированного сценария поиск
и повторный выбор управления не запускаются.

```text
Model_Z_final_OPM.zip
 → банк сценариев OPM (базовый прогон, канонический экспорт, полные 224 месяца)
 → связность INIT/EGRID → connectivity.json
 → обучение Google TimesFM (девять экономических выходов, полный backbone)
 → оценка на закреплённом наборе с неизменным разбиением
 → поиск: сетка + раунды Qwen, официальный калькулятор по прогнозным рядам,
   ограничения собственных заданий скважин → фиксация выбора
 → ровно один финальный OPM + официальный ЧДД → парный аудит
```

Внутри поиска нет вызовов OPM. Прогнозный ЧДД не является официальным:
официальным считается только результат калькулятора организаторов на выходе
OPM при сопоставимой парной базе. После финального физического результата
выбор другого графика запрещён.

Qwen не подменяет численные ворота: он предлагает и критикует. Валидатор
ограничений, симулятор и калькулятор ЧДД остаются детерминированными.

## Что реализовано

- совместный прогноз TimesFM 3.0 на 103 скважины и 224 месяца с плановыми
  управлениями, геологией и связностью;
- девять экономических выходов прогноза → таблица официальной экономики;
- генерация воспроизводимого банка сценариев управления и режимов BHP;
- последовательные прогоны сценариев в OPM Flow с проверкой происхождения входов;
- поиск графика по прогнозному ЧДД с ограничениями собственных заданий скважин
  и криптографической фиксацией выбора до единственной финальной проверки;
- расчёт ЧДД официальным Python-калькулятором и парное сравнение полного периода;
- AIOS с четырьмя ролями: координатор, инженер по разработке, планировщик, критик;
- внешний Qwen `qwen3.8-27b` через API Татнефти; локальная LLM не используется;
- Docker-образ API и конфигурация запуска.

## Структура

```text
src/timesoil/aios/   цикл MPC, OPM и канонический экспорт, адаптер официального
                     калькулятора, ограничения, расписания, прогнозные адаптеры,
                     агенты и клиент LLM, API, CLI, веб-страница
scripts/             банк сценариев, связность, обучение и оценка TimesFM,
                     поиск политик, фиксация и финальная проверка, сравнение
tests/               контрактные и численные проверки
CHDD_PYTHON/         официальный калькулятор и нормативы организаторов
config/              пример конфигурации без секретов
*.csv, *.json         входные наборы для тестов и итоговый запрос с квитанцией
```

## Быстрый запуск

Требования: Python 3.13, `uv`, Docker и образ OPM Flow, закреплённый в
`src/timesoil/aios/opm.py`.

```bash
uv sync --locked
uv run python -m compileall -q src scripts
uv run pytest tests -q
uv run timesoil-aios doctor
```

API:

```bash
cp config/aios.example.env config/aios.env
# проверить маршрут Татнефти в config/aios.env; API-ключ хранить отдельным файлом
mkdir -p secrets && chmod 700 secrets
printf '%s' "$QWEN_API_KEY" > secrets/qwen_api_key
chmod 600 secrets/qwen_api_key
docker compose --env-file .env.example up -d --build --wait --wait-timeout 180
curl --noproxy '*' --fail http://127.0.0.1:8000/health
curl --noproxy '*' --fail http://127.0.0.1:8000/v1/capabilities
```

Операторский веб-интерфейс поднимается тем же контейнером и доступен по адресу
`http://127.0.0.1:8000/app/`; статика лежит в `frontend/` и копируется внутрь
образа. Данные расчётов интерфейс читает через API `/v1/results`: каталог
результатов хоста (по умолчанию `./results`, переопределяется переменной
`TIMESOIL_RESULTS_DIR` в `.env.example`) монтируется в контейнер только на
чтение как `/app/results`, и туда же указывает `TIMESOIL_RESULTS_ROOT`.

Compose использует минимальный bootstrap с правами только на чтение секрета и
смену UID/GID. Перед запуском API он сбрасывает capabilities и переходит на
UID/GID `10001`; сам API от root не работает.

Остановка без удаления сохранённых расчётов:

```bash
docker compose --env-file .env.example down
```

Исходный архив Model Z, веса TimesFM и объёмные выходные файлы OPM в Git не входят.
Единственный путь проверки итогового сценария — команда `timesoil-aios full-cycle`
с `TRACK2_FINAL_REQUEST.json`, приведённая выше.
Подтверждение результата требует `full-cycle-receipt.json` и связанных
с ним манифестов, созданных самим прогоном.
