# Scorp — Track 2 Model Z

Финальный пакет команды Scorp для синтетического месторождения Z. Горизонт управления: 01.01.2007–01.09.2025, 103 скважины, 224 месяца, 23 072 помесячных действия. В корне репозитория находится **один** выбранный график управления.

## Результат полного цикла

27.09.2026 запрос проверен на чистом коде GitLab `final` (`f0ff4bbd1ffb3f54b29d7f1d65e30929e4ebce10`). OPM Flow выполнил расчёт на A100; Qwen `qwen3.8-27b` вызывался только через Tatneft LiteLLM. Полный цикл занял **303 с**, сделал 8 вызовов Qwen без ошибок и завершился квитанцией `complete=true`, `critic_approved=true`.

## Как получен график

Это зафиксированная после физических проверок комбинация двух ранее рассчитанных вариантов: управление F3 в 2007 году, распределение CRM-B с января 2008 года, снижение заданий нагнетательных на 4% в 2010–2012 годах. Скважина №94 остановлена на сентябрь 2011 года, чтобы исключить отрицательный поток при экспорте; перевод скважины №19 под закачку с февраля 2013 года и все 16 ремонтов сохранены. Управления не изменяются во время финального полного цикла.

В репозитории есть код TimesFM и AIOS. Для этого итогового гибрида **автоматический выбор TimesFM или Qwen не подтверждён**: корректировки и фиксацию сделал оператор по результатам OPM. В финальном полном цикле Qwen проверяет дайджест действий до расчёта и итоговые доказательства после него; он не переписывает график. [Трёхстраничная схема](TRACK2_FINAL_SCHEME.drawio) показывает скважины, параметры управления, ветви проверки, численные графики и источники ЧДД.

ЧДД прежнего режима при том же архиве, горизонте и нормах — 3 871,979375 млн ₽. Арифметическая разница составляет **+158,296288 млн ₽ (+4,088%)**. Прежний режим сам нарушает VRR и давление, поэтому это численное сравнение, а не сертифицированный прирост к допустимой базе. Квитанция помечена `experimental=true`, `organizer_certified=false`; сертификацию выполняют организаторы.

Для новой среды нужен тот же архив по доступному пути, Python 3.13, Docker с закреплённым образом OPM и доступ к Tatneft LiteLLM. Повторный запуск создаёт собственную квитанцию:

```bash
export LLM_BASE_URL=https://litellm.tatneft.guru/v1
export LLM_MODEL=qwen3.8-27b
# LLM_API_KEY передать через защищённое окружение, не сохранять в Git
uv run timesoil-aios full-cycle TRACK2_FINAL_REQUEST.json --runs-dir results --run-id final --timeout 7200
```
